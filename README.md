# Skills IA - Collection de Compétences pour Agents IA

Ce dépôt regroupe une collection de compétences standardisées (**Agent Skills**) conçues pour les assistants et agents de code IA (Claude Code, Gemini, Cursor, Copilot, etc.), axées particulièrement sur Google Cloud Platform (GCP), BigQuery, le Data Engineering et le Machine Learning.

## 📁 Contenu du dépôt

| Compétence | Description |
| :--- | :--- |
| `accidental-data-loss-prevention` | Prévention et bonnes pratiques contre les pertes accidentelles de données |
| `bigquery-data-transfer-service` | Gestion et automatisation des transferts de données BigQuery (DTS) |
| `bigquery-sql` | Optimisation de requêtes SQL BigQuery, partitionnement et clustering |
| `building-data-apps` | Conception d'applications de données avec Streamlit, FastAPI, React |
| `data-autocleaning` | Nettoyage automatisé des données et scans Dataplex |
| `dataform-bigquery` | Modélisation et pipelines de transformation avec Dataform sur BigQuery |
| `dbt-bigquery` | Modélisation des données avec dbt (data build tool) sur BigQuery |
| `discovering-gcp-data-assets` | Cartographie et découverte des assets de données sur GCP |
| `enforcing-resource-attribution` | Attribution des coûts et tagging des ressources cloud |
| `gcp-data-pipelines` | Architecture et mise en place de pipelines de données sur GCP |
| `gcp-dataflow` | Traitement par lots et streaming avec Apache Beam / Google Cloud Dataflow |
| `gcp-pipeline-orchestration` | Orchestration de flux de travail (Cloud Composer / Airflow, Workflows) |
| `gcp-pipeline-resource-provisioning`| Provisionnement d'infrastructure pour pipelines de données |
| `gcp-spark` | Exécution de jobs Spark sur Dataproc et Dataproc Serverless |
| `gcp-spark-troubleshooting` | Diagnostic et résolution des erreurs courantes sur Spark / Dataproc |
| `google-cloud-auth-verification` | Vérification des identifiants et des accès IAM sur GCP |
| `managing-python-dependencies` | Gestion des dépendances Python (uv, poetry, pip-tools) |
| `ml-best-practices` | Bonnes pratiques d'ingénierie et cycle de vie Machine Learning |
| `notebook-guidance` | Standards de conception et d'exécution des notebooks Jupyter/Colab |
| `schema-mapping` | Mappage et alignement de schémas de données hétérogènes |
| `skill-repair` | Diagnostic et réparation des compétences d'agents |

---

## 🚀 Utilisation

Chaque sous-dossier dans `skills/` contient :
- Un fichier `SKILL.md` avec le frontmatter et les instructions détaillées pour l'agent.
- Des scripts d'aide (`scripts/`), des exemples (`examples/`) ou de la documentation de référence (`references/`).
